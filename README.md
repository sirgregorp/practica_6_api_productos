# Práctica 6 - API REST de productos

## Cómo ejecutar

```bash
npm install
npm run dev
```

El servidor corre en http://localhost:3001

## Endpoints

| Método | Ruta              | Estado        |
|--------|-------------------|---------------|
| GET    | /productos        | Implementado  |
| GET    | /productos/:id    | Implementado  |
| POST   | /productos        | Completado |
| PUT    | /productos/:id    | Completado |
| DELETE | /productos/:id    | Completado |

Las pruebas las hice con Thunder Client en VS Code.
